# Settlement Message Text Simplification & VietQR Image Sharing Design

## Overview
Simplify the session settlement announcement text generated by `generateSessionSettlementText` in `app/utils/sessionSocialShare.ts` to match the user's exact concise format, and enhance `app/components/session/SocialShareModal.vue` to preview the generated VietQR code card and allow 1-tap copying of the actual QR image and native sharing with the QR image file attached.

## 1. Settlement Text Format (`app/utils/sessionSocialShare.ts`)

The settlement message is streamlined to the essential financial metrics:

```text
🏸 TỔNG KẾT TIỀN SÂN - GRAVITY BADMINTON
📅 Ngày: <session.date> | 📍 <session.location>
🏟️ Số lượng sân: <session.courtNumber || 1>
🙌 Tổng số người: <totalActualPlayers>
💰 Chi phí: Sân <courtCost>đ + Cầu (<shuttlecocksUsed> quả = <shuttleCost>đ) = <totalCost>đ
💵 Tiền sân/người: <feePerPerson>đ / người
```

### Calculation & Field Mapping:
- `session.date`: Formatted session date string (e.g. `2026-09-06`).
- `session.location`: Session venue location name.
- `Số lượng sân`: `session.courtNumber || 1`.
- `Tổng số người`: Count of all actual attendees including their guests:
  ```ts
  const actualPlayers = (attendances || []).filter((a: any) => a.actualAttended);
  const totalActualPlayers = actualPlayers.reduce(
    (acc: number, a: any) => acc + 1 + (a.guestCount || 0),
    0,
  );
  ```
- `Chi phí`:
  - `courtCost`: `financials?.courtCost || 0`
  - `shuttlecocksUsed`: `financials?.shuttlecocksUsed || 0`
  - `shuttleCost`: `shuttlecocksUsed * (financials?.shuttlecockPrice || 0)`
  - `totalCost`: `courtCost + shuttleCost`
- `Tiền sân/người`: `financials?.calculatedFeePerPerson || 0`

All amounts formatted with Vietnamese currency separator: `toLocaleString('vi-VN')}đ`.

## 2. VietQR Card Preview in `SocialShareModal.vue`

### VietQR URL Computation:
When on the Settlement tab, compute the dynamic VietQR URL:
```ts
const vietQRUrl = computed(() => {
  if (props.session?.paymentQR) {
    return props.session.paymentQR;
  }
  const bankInfo = props.session?.bankInfo;
  if (!bankInfo?.accountNumber || (!bankInfo?.bankName && !bankInfo?.bankCode)) {
    return '';
  }
  const feePerPerson = props.financials?.calculatedFeePerPerson || 0;
  const memoDate = props.session?.date ? props.session.date.replace(/-/g, '') : '';
  return generateVietQRUrl({
    bankId: bankInfo.bankCode || bankInfo.bankName,
    accountNumber: bankInfo.accountNumber,
    accountName: bankInfo.accountName,
    amount: feePerPerson > 0 ? feePerPerson : undefined,
    memo: `BDM ${memoDate}`.trim(),
    template: 'compact2',
  });
});
```
The `compact2` template generates a full banking card image containing the QR code, bank logo, account holder name, account number, exact fee amount, and memo.

### Visual Preview Component:
Below or adjacent to the text preview in `SocialShareModal.vue`:
- If `vietQRUrl` exists, render a clean card showing:
  - The QR image (`<img :src="vietQRUrl" />`) with loading state and error handling.
  - A quick-action button **"Sao chép ảnh QR"** (Copy QR Image) right on the preview card.

## 3. Actions & Sharing Flow

### Action 1: Copy Text
- Triggers `navigator.clipboard.writeText(currentText.value)`.
- Shows Toast notification: `common.copied` / `socialShare.toastCopied`.

### Action 2: Copy QR Image (`copyQRImage`)
- Downloads the QR image as a `Blob` (`fetch(vietQRUrl)` or canvas drawing fallback).
- Writes to clipboard via `navigator.clipboard.write([new ClipboardItem({ 'image/png': blob })])`.
- Shows Toast: `socialShare.toastQRCopied` ("Đã sao chép ảnh QR vào bộ nhớ tạm").
- Visual button feedback: changes icon to green Checkmark for 2.5s.

### Action 3: Native Share (`handleNativeShare`)
- If `vietQRUrl` exists and `navigator.canShare`:
  - Fetch blob and construct `const file = new File([blob], 'vietqr.png', { type: 'image/png' })`.
  - Check `navigator.canShare({ files: [file] })`.
  - If true: call `navigator.share({ title: `Badminton - ${props.session?.date}`, text: currentText.value, files: [file] })`.
  - If false (or fails): fallback to `navigator.share({ title: `Badminton - ${props.session?.date}`, text: currentText.value, url: sessionUrl.value })`.
